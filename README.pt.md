Framework modular, multilíngue e sensível a variedades regionais para detecção e humanização de escrita de IA com **CLI de Terminal** completa (zero dependências externas, Python padrão).

---

## ⚡ Início Rápido CLI

```bash
# Execução direta
./bin/txt-humanizer --help

# Detectar idioma, variedade regional e sinais humanos
txt-humanizer detect "Texto para analisar..."

# Verificação de documento com pontuação e citações de evidências
txt-humanizer check documento.md
```
