Framework modular, multilingüe y sensible a variedades regionales para la detección y humanización de textos generados por IA con **CLI de Terminal** completa (sin dependencias externas, estándar Python).

---

## ⚡ Inicio Rápido CLI

```bash
# Ejecución directa
./bin/txt-humanizer --help

# Detectar idioma, variedad regional y señales humanas
txt-humanizer detect "Texto para analizar..."

# Verificación con puntuación y citas de evidencia
txt-humanizer check documento.md
```
